## About

I'm a Computer Science & Engineering student and software builder focused on artificial intelligence, machine learning, and full-stack software development. 

I enjoy bridging the gap between theoretical concepts and working systems—whether that means training computer vision neural networks, writing lightweight system monitoring daemons, or building responsive web tools. My approach is to understand systems from first principles and build software that is clean, practical, and dependable.
